Named Data Radio · on-air wire format

The bytes on air — what a second implementation must match

Every field read from the shipping code. The destination address is not an address — it is a prefix-set Bloom filter. The source is not a MAC — it is an ephemeral nonce that rotates every 5 minutes. Nothing announces a schedule; the slot and channel are computed from the name.

Verified byte-for-byte against source · RFC-2119 conformance

01The injected frame, end to end

A full monitor-mode inject: a radiotap TX header, the 802.11 MAC header, LLC/SNAP, the EtherType, then the LP-framed NDN packet.

02The 802.11 header — addresses that aren't addresses

Frame Control is 0x08 0x00 (a Data frame, not QoS-Data). The three address fields carry the name filter and the nonce — two layouts, chosen by whether a name is in hand.

Tier-0 layout (a name is present): the 12-byte Bloom filter fills addr1‖addr2; the nonce moves to addr3. Legacy layout (no name — a non-first fragment): addr1 = broadcast, addr2 = nonce, addr3 = copy of addr1.

03The Blurred Name — 94 bits, 4 hashes

A prefix-set Bloom over the 12 address bytes. Two bits are reserved (forced local + group so it can never look like a host MAC); 94 bits carry the set. Every prefix of the name is inserted with 4 SipHash-double-hashed bit positions. A receiver ANDs its prefix mask: a miss is exact (zero false negatives), a hit costs only a parse.

byte 0, bit by bit — the two reserved bits
Insertion positions: h1 = siphash(key, prefix), h2 = siphash(key2, prefix) | 1, then bit_i = (h1 + i·h2) mod 94 for i∈0..4. Usable bit p → physical bit p+2. Admission cap: a filter with popcount > 48 matches nothing (the universal-wake bound).

04The three small structures

Link-FEC header · magic 0xFC · 6 B
Segments wrapped [len:u16 BE] ‖ payload. The N frames of a generation must span separate MPDUs.
Time beacon · magic 7E 54 42 · 11 B
Injected raw — never through the slot gate, so the clock never waits on a data slot. The protocol's only periodic frame.
Reception report · magic 0xCD v2 · all little-endian · /localhop/radio/report/<node>
The only versioned structure. v1 omits max_rx_mcs and is read as fully-capable (9). Vectors are u8-count-prefixed, each capped at 32.

05Computed, not transmitted

The slot and channel are never on the wire. Both endpoints compute them from the name's unkeyed FNV hash and the common-view epoch — the wire filter uses keyed SipHash, the computed access uses unkeyed FNV, and only the name normalization is shared (#44).
