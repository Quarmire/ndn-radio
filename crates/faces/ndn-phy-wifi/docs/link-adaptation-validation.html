Named Data Radio · link adaptation · HOW-WELL

How well a name is carried — rate, redundancy, and the target that rules them

A named broadcast radio has no PHY ACKs and must serve every receiver with one transmission — the worst-receiver penalty. Rate, FEC, and coding all move delivery, but not equally. Measured: the name's own reliability target is the master dial; coding is a smaller lever; rate selection is mandatory; and the lease a name reserves in time is its link decision.

Fourth MAC facet — mostly built & on air; ranked and bounded in sim

01Three levers, ranked by measured airtime

Deliver a K=32 generation to a heterogeneous group (−84…−56 dBm) with one straggler below MCS0's floor. Airtime for the alarm case (serve everyone) and the bulk case (drop the straggler).

02The lease is the link decision

A name's slot length should equal the airtime its adapted rate needs — not a fixed constant (slot_us, #85). Delivery is split by class, because raw name count is a rigged metric: a small slot scores high by dropping every alarm and packing cheap bulk.

03The ephemeral count discounts FEC — but it's doubly gated

The rotating source nonce can't carry per-peer rate state, so it doesn't — it supplies the neighbour count, which discounts parity by phy^n. A real lever, valid only under two assumptions.

04The spine — three observations across the facet

  1. The name's reliability semantics is the master control. It sets the airtime target (§1), the lease length (§2), and whether the pooling discount is even legal (§3). Rate, FEC, and coding are subordinate knobs beneath the class bit.
  2. The shared-map law, third appearance. Occupancy had to be shared for rendezvous, link-state for the schedule, correlation/count for pooling. Every facet needs a shared view or it breaks — a structural invariant of the whole MAC.
  3. Feedback is named, not ACKed. Reception reports close the RSSI loop; re-Interest closes the rate loop; overhear senses but does not confirm (a re-forward rides a different channel). The control plane is the data plane — again.

05What this doesn't settle

  • fec_redundancy's phy^n is ungated — no any-of/all-of semantics check, no correlation input. As written it under-provisions an alarm name at high count and any name on a contended channel. The sharpest actionable finding.
  • The rate → lease closure is unactuated — SlotSchedule::from_airtime has zero production callers (#85); the slot is still an env constant. The sim shows the payoff; the wiring is pending.
  • Per-frame PER / TxReport (#42) — worth it? Delivery is already inferred from re-Interest at object granularity. The honest home for per-frame PER is overhear sensing, not a PHY ACK. Measure before building the driver work.
